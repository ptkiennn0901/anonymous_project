# Sample data layout

Approved samples will be added only after privacy review.

```text
data/
  xray/<random_sample_id>/image.ext
  ct/<random_sample_id>/volume_or_derived_image.ext
  mr/<random_sample_id>/volume_or_derived_image.ext
  pet_ct/<random_sample_id>/volume_or_derived_image.ext
```

Each sample directory may include a de-identified report excerpt only after text-level PHI review. No source case ID, original series name, or original file name is permitted.
